# HireHi Scraper

Скрипт для получения данных о вакансиях с сайта hirehi.ru

## Описание

Программа получает информацию о QA вакансиях с удаленной работой (senior/middle, auto) через API hirehi.ru и выводит список с названиями компаний и зарплатами в логи.

**Дополнительная фильтрация:** Скрипт фильтрует вакансии по наличию ключевых слов "Kotlin" или "Android" в полях описания и требований.

## Установка

1. Создайте виртуальное окружение:
```bash
python -m venv venv
```

2. Активируйте виртуальное окружение:
```bash
# Linux/macOS
source venv/bin/activate

# Windows
venv\Scripts\activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Использование

1. Убедитесь, что виртуальное окружение активировано
2. Запустите скрипт:
```bash
python hirehi_scraper.py
```

## Что делает скрипт

1. Обращается к API `https://hirehi.ru/api/search/jobs` с параметрами:
   - category=qa
   - format=удалённо
   - level=senior&level=middle
   - subcategory=auto

2. Обрабатывает пагинацию и получает все доступные вакансии

3. **Фильтрует вакансии** по наличию ключевых слов "Kotlin" или "Android" в полях:
   - `description_details` (описание вакансии)
   - `requirements_details` (требования)

4. Извлекает информацию:
   - Название компании
   - Название вакансии
   - Зарплата
   - Уровень (senior/middle)
   - Формат работы
   - Ссылка на вакансию

5. Выводит результаты в консоль и сохраняет в файл `hirehi_filtered_jobs.json`

## Логи

Все операции логируются в:
- Консоль (в реальном времени)
- Файл `hirehi_scraper.log`

## Выходные файлы

- `hirehi_scraper.log` - лог файл с подробной информацией
- `hirehi_filtered_jobs.json` - JSON файл с отфильтрованными вакансиями (содержащими Kotlin/Android)
